# Pocket Reader

A phone-friendly viewer for Word documents and text files. It runs entirely in the
browser, so files never leave the device.

| File type | What you see |
|---|---|
| .docx | Headings, bold/italic, lists, tables, links and pictures (via mammoth.js) |
| .doc (Word 97-2003) | Full text without formatting (built-in reader) |
| .txt, .md, .log, .csv | Text exactly as written (UTF-8, UTF-16 and Latin-1 detected) |

Reading tools: text size, a soft rounded or serif typeface, light/dark, find-in-document, and a
"recently opened" list kept on the device.

## Mobile app (iOS and Android)

The app is wrapped with [Capacitor](https://capacitorjs.com), so the same web code
runs as a native app. App id: `com.superduty335.pocketreader`.

**Install on Android now:** every push runs the *Build apps* workflow. Open the
latest run under the repo's **Actions** tab, download `pocket-reader-android`,
unzip it and open `app-debug.apk` on your phone (allow installs from your browser
or Files app when asked).

**Open files from other apps:** the app registers for .docx, .doc and .txt.
On Android, open a file from Files, Gmail or Drive, pick Pocket Reader and tap
*Always* to make it the default. On iPhone, use *Share* or *Open in* and pick
Pocket Reader (iOS doesn't let you change the default app for documents).

**Build locally:**

```sh
npm ci
npm run sync          # rebuild the web page and copy it into android/ and ios/
npx cap open android  # Android Studio: Run, or Build > Generate Signed Bundle for Play
npx cap open ios      # Xcode on a Mac: pick your team, then Run or Product > Archive
```

**Publishing:** Google Play needs a developer account ($25 one-time) and a signed
release bundle. The App Store needs an Apple Developer account ($99/year); the iOS
CI job only checks that the app compiles, since signing needs your Apple certificates.

Icons and splash screens come from `assets/` (`npx capacitor-assets generate`).

## Use it in a browser

- **Hosted link:** open the Claude artifact link on your phone and tap *Open file*.
- **Offline copy:** `dist/pocket-reader.html` is one self-contained file. Put it on
  your phone (AirDrop, Files, Drive) and open it in the browser, or host it on any
  static site (GitHub Pages, Netlify) and use *Add to Home Screen* to get an app icon.

## Files

- `src/app.html` - the app (HTML, CSS, JS)
- `vendor/mammoth.browser.min.js` - mammoth 1.13.0 (BSD-2-Clause) for .docx
- `build.py` - builds `dist/pocket-reader.html` (offline, library inlined),
  `dist/artifact.html` (library from jsDelivr) and `www/index.html` (the app's web content).
- `android/`, `ios/` - native projects generated by Capacitor
- `assets/` - icon and splash source images

## Limits

- Old .doc files show text only; Word 6/95 and password-protected files are not supported.
- .docx layout is simplified for reading (no page layout, headers/footers or comments).
